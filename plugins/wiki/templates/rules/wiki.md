# Wiki

The wiki is `docs/wiki/` of this environment; `nook wiki shelves` names each shelf and its use. It holds what lasts. Work in progress stays with its work.

- Read the index first: `docs/wiki/INDEX.md`, then the `INDEX.md` of a shelf. Open a page only when its line matches the task.
- Name each page that you use, as `(wiki: resources/shipments-api.md)`. A fact from a page with no link is a guess.
- Write a page only after the owner says yes to the draft. Never delete or merge a page without the owner's yes.
- A page states how a thing is now, with its source. Each change adds one History line, never the story of the work.
- Give each point a real example. An adjective with no example is not a point.
- The shelf `areas/` belongs to the owner. Read it; never write it.
- After a page changes, run `nook wiki index --fix` and `nook wiki links`.
