## Nook

This folder is a desk of Nook. Packs on here: {{packs}}. Every folder inside it gets these words and these packs.
The base rules are in `.claude/rules/nook/`. Your own rules and notes go outside this block; `nook init --update` replaces only the block.
Run `nook doctor` to see the desks above this folder, the packs each one gives, and every gap with its fix.
