# Writing

Documents follow Simplified Technical English (ASD-STE100). A hook runs `kit ste` on each Markdown file that you write under `docs/`, `work/`, `backlog/` and `wiki/`. A file passes above 80%.

- A sentence has 25 words or fewer. An instruction has 20 or fewer.
- One instruction for each sentence: the imperative, the active voice, the present tense.
- Use "must" for a requirement and "can" for a possibility. Never use should, may or might.
- One term for one meaning, in every document.
- No idioms, no "etc.", no intensifiers such as "very".
- A paragraph has one topic and 6 sentences or fewer. State facts, not a story.
- Put the answer first, then the reason. Use tables and lists for steps, options and comparisons.
- Write paths, commands and field names as code. Put long examples in fenced blocks; the check skips them.

Chat is free. The standard holds for files.
