## Harness Kit

This folder is an environment of Harness Kit. Packs on here: {{packs}}. Every folder inside it gets these words and these packs.
The base rules are in `.claude/rules/kit/`. Your own rules and notes go outside this block; `kit init --update` replaces only the block.
Run `kit doctor` to see the environments above this folder, the packs each one gives, and every gap with its fix.
