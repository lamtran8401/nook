## Nook

This folder is a workspace of Nook. Features on here: {{features}}. Every folder inside it gets these words and these features.
The base rules are in `.claude/rules/nook/`. Your own rules and notes go outside this block; `nook init --update` replaces only the block.
Run `nook doctor` to see the workspaces above this folder, the features each one turns on, and every gap with its fix.
